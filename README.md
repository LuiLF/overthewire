# OverTheWire — Wargames

Repositório dedicado à documentação dos meus estudos práticos nos [wargames do OverTheWire](https://overthewire.org/wargames/), com foco no desenvolvimento de conhecimentos em Linux, redes e segurança da informação.

O objetivo é registrar os conceitos explorados, as ferramentas utilizadas e os aprendizados adquiridos ao longo dos desafios, priorizando a compreensão dos procedimentos em vez da reprodução de soluções.

## Wargames

| Wargame | Área de estudo | Status |
|---|---|---|
| [Bandit](./bandit/README.md) | Fundamentos de Linux e linha de comando | Em andamento |

## Metodologia

Durante os estudos, procuro:

- Compreender o objetivo de cada desafio antes de buscar uma solução.
- Investigar ferramentas, comandos e abordagens possíveis.
- Registrar conceitos, dificuldades e aprendizados relevantes.
- Documentar os exercícios sem divulgar senhas ou credenciais dos níveis.
